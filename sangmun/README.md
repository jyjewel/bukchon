# 尙古圖會 · 의고문 주사위놀이 (시범판)

박규수 『尙古圖會文義例』를 바탕으로 한 멀티플레이 웹 게임 프로토타입.

```
node server.js          # http://localhost:3000  (PORT, ROUNDS, WRITE_SEC, VOTE_SEC 환경변수로 조절)
```

의존성 없음 (Node 18+). 방 코드로 2~6명이 접속한다.

## 규칙
1. 라운드마다 고사 카드(원문 + 박규수 안설)가 공개된다.
2. 차례인 사람이 주사위를 굴리면 **눈 → 문체**가 정해진다 (카드마다 눈별 문체가 다름).
3. 모두 그 문체로 의고문을 짓는다.
4. 글이 익명으로 공개되고, 자기 글을 뺀 한 편에 투표한다.
5. 제출 +1, 득표당 +2, 말(隱逸·文治·武略·節義·正直·詞藻) 테마가 카드와 같으면 +1.

## 데이터
`data/gosa.json` 13장은 권1~2 OCR 샘플에서 옮긴 시범 데이터다.
- OCR 오류를 일부 임의로 교정했고(예: 梅充臣→梅堯臣), 눈별 문체 배정도 OCR 기준이라 **원본 대조 필요**.
- 카드의 말(`theme`) 분류는 임시 지정.
- 긴 안설은 앞부분만 수록.
